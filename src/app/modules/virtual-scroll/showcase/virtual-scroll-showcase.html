Custom virtual scrolling for dynamic-height organization groups

A focused reconstruction of a large organization selector. A custom Angular CDK VirtualScrollStrategy keeps search and selection behavior intact while limiting DOM work to the visible portion of a hierarchy whose items do not share a fixed height.

About the data

This reconstruction uses deterministic synthetic organizations and contains no customer or production data. Search-to-paint values are measured locally in your browser.

Implementation

A custom strategy for variable-height items

Each top-level organization and its children form one virtual item. Estimates provide an immediate layout; browser measurements refine the offset map after rendering.

Core implementation

Fixed itemSize scrolling cannot model groups with different child counts. This custom VirtualScrollStrategy uses stable Angular CDK extension points rather than the experimental autosize package. 

<cdk-virtual-scroll-viewport
  [appVariableSizeVirtualScroll]="estimatedHeights()">
  <li *cdkVirtualFor="let group of groups; let index = index"
      [appMeasureVirtualItem]="index">
</cdk-virtual-scroll-viewport>
